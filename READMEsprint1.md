# Fraud Detection — Data Cleaning & Feature Engineering

A two-person pipeline that takes the raw credit card fraud dataset
(100,000 transactions) through cleaning, validation, EDA, and feature
engineering to produce a model-ready dataset.

## Folder structure

```
├── data/
│   └── raw_fraud_data.csv          # original raw dataset (input)
├── sheetal/                        # Data cleaning & validation (Sheetal)
│   ├── 01_data_cleaning.py
│   ├── 02_missing_value_handling.py
│   ├── 03_data_validation.py
│   ├── 04_behavioral_analysis.py
│   ├── 05_visualizations.py
│   └── 06_documentation.md
├── riya/                           # Feature engineering (Riya)
│   ├── 01_data_processing.py
│   ├── 02_feature_engineering.py
│   ├── 03_temporal_features.py
│   ├── 04_geospatial_features.py
│   ├── 05_customer_behavior_features.py
│   └── 06_documentation.md
├── output/                         # Reports & charts generated by the pipeline
│   ├── data_validation_report.md
│   ├── behavioral_analysis_report.md
│   └── visualizations/
│       ├── 01_class_distribution.png
│       ├── 02_amount_distribution.png
│       ├── 03_fraud_rate_by_category.png
│       └── 04_fraud_rate_by_hour.png
└── requirements.txt
```

## Pipeline flow

```
raw_fraud_data.csv
      │
      ▼
sheetal/ 01 → 02 → 03  (clean → handle missing → validate)
      │
      ▼
sheetal_03_validated.csv
      │
      ▼
riya/ 01 → 02  (process → engineer features + encode)
      │
      ▼
final_preprocessed_dataset.csv   (model-ready)
```

Sheetal's `04_behavioral_analysis.py` and `05_visualizations.py` run off the
validated dataset independently, producing the reports/charts in `output/`.

## How to run

```bash
pip install -r requirements.txt

cd sheetal
python 01_data_cleaning.py
python 02_missing_value_handling.py
python 03_data_validation.py
python 04_behavioral_analysis.py
python 05_visualizations.py

cd ../riya
python 01_data_processing.py
python 02_feature_engineering.py
```

All intermediate/output CSVs (cleaned data, final model-ready dataset) are
regenerated by running the scripts above — they aren't stored in this repo
to keep it lightweight. The `output/` folder here already contains the
reports and charts from the last run, for quick viewing on GitHub.
